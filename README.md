One funny out-of-office auto-reply written as if a houseplant sent it: the fern, unwatered since March, has learned to type — and its only message is a demand for water, not emails.

## Run it

```sh
node main.ts
```

This writes the entry text to `/output/entry.txt`.

The entry text is 113 Unicode code points long.
